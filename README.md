
# CAN-FD Signal Packing Timing Evaluation

This release candidate studies how frame packing changes CAN-FD RX inter-arrival jitter under a fixed 64-byte mixed-period workload implemented on RA6M5 TX/RX bare-metal firmware.

The workload uses three layouts: A distributes the 5 ms signals across 8 B, 8 B, and 16 B frames and the 50 ms signals across 8 B, 8 B, and 16 B frames; B uses one 32 B frame per period group; C packs all 64 B into one 5 ms frame, including repeated normal signals. Repeated payloads for the same ID are byte-identical to control bit-stuffing variation.

Key results: A60 59.764 us, C60 22.098 us, difference 37.667 us; reconstructed occupancy difference -0.091382 pp (strict matched); 120/120 files passed QC. The 80% full-ordering claim gate failed.

The PCAN TRC metric is RX inter-arrival jitter, not one-way latency. Reconstructed occupancy is not measured PCAN actual load, and the oscilloscope marker study is a separate campaign. The study does not validate motor stability, PID vibration, or physical PWM edges. Optional dummy-load frames are generated by the same TX node, so the results do not isolate pure external-bus contention.

See the [full Korean method and limitations](README_KO.md), [analysis figures](analysis/figures/), [summary tables](analysis/summary_tables/), and [synthetic sample data](sample_data/). The final statistics require the excluded private 120-TRC source dataset; the sample is for format checking only.
