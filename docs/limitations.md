
# Limitations

The study does not measure pure bus latency or PCAN actual load and does not validate motor stability, PID vibration, or physical PWM edges. Scope and TRC results come from separate campaigns. The 80% full-ordering gate failed. Blocking is discussed as a mechanism, not established as a single confirmed cause. Optional dummy-load frames originate from the same TX node, so the experiment does not isolate pure external-bus contention.
