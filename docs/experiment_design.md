
# Experiment Design

- Conditions: baseline, 30%, 60%, 80%
- Strategies: A, B, C
- Runs: 10 per strategy-condition cell
- Total: 120 TRC files
- Primary metric: 0x100 RX inter-arrival jitter
- Fairness control: byte-identical repeated payloads
- Load matching: payload-aware reconstructed occupancy with strict/near/unmatched gates
